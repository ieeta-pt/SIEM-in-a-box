      How it works
      
Collection and processing, decoupled.

      
Collectors push compressed JSON to Kafka. Logstash consumes each source through its own pipeline, maps it to ECS and indexes it. Kibana turns it into detections, alerts and timelines.

    

    

      
01 · Collect
Your hosts
Filebeat, Winlogbeat, rsyslog or Elastic Agent.

      

      
02 · Buffer
Kafka
Durable topic per source. Survives backend restarts.

      

      
03 · Process
Logstash
Isolated pipelines parse, enrich and map to ECS.

      

      
04 · Store
Elasticsearch
Secured with TLS and X-Pack out of the box.

      

      
05 · Detect
Kibana
Detection rules, alerts, dashboards, Fleet.

      Why it matters
      
Built for the bad day, not the demo.

      
Small teams cannot babysit a SIEM. SIEM-in-a-Box is designed around the failures that actually happen: a backend restart, a noisy web server, a sender that cannot retry.

    

    

      
One-command deploy
A single make up generates certificates, sets passwords and starts every service in the right order with health checks.

      
No loss on outages
Kafka holds events while Elasticsearch or Logstash is down, protecting UDP syslog senders that cannot pause or retry.

      
Isolation under flood
A pipeline per source means 6,000 web events/s do not delay authentication events. Attack-stream p95 stayed at 0.3 s.

      
Detections that fire
Kibana's Detection Engine on ECS-normalised data, with scripts to provision and manage rules as code.

      
Policies as code
Terraform manages Fleet Server, integrations and four ready agent policies for Linux, web servers and Windows.

      
Measured, not claimed
Every number on this page traces to a derived table and the runs that produced it, with the harness to reproduce them.

      Get started
      
Up in five minutes.

    4. 
      

    

    

      

        

# 1. Clone and start the stack
$ git clone https://github.com/ieeta-pt/SIEM-in-a-box.git
$ cd SIEM-in-a-box
$ make up

# 2. Kibana → https://localhost:5601  (elastic / elastic)

# 3. On a monitored Linux host
$ sed -i 's/<IP_DO_SIEM>/192.168.0.23/' /etc/filebeat/filebeat.yml
$ systemctl enable --now filebeat

      

      
Requires Docker Engine 24+ with Compose and 8 GB of RAM for Docker. Change the default passwords before any real deployment.
